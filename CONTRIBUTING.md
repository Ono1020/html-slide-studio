# Contributing

Thank you for your interest in contributing to HTML Slide Studio.

## Before you start

- Check the existing issues and pull requests before opening a new one.
- For substantial feature work, open an issue first to discuss the problem and proposed approach.
- Keep changes focused and include tests for behavior changes.

## Development

```bash
npm install
npm run dev
```

Before submitting a pull request, run:

```bash
npm test
npm run lint
npm run build
```

## Pull requests

- Use a descriptive title and explain the user-facing impact.
- Link related issues.
- Include screenshots for visible UI changes when useful.
- Report test commands and results.
- Do not include generated build output, secrets, or unrelated formatting changes.

## Code of conduct

Be respectful and constructive. Harassment and discriminatory behavior are not acceptable.
